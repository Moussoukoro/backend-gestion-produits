#  Backend -Gestion de Produits avec Express & MongoDB

##  Description

Ce projet constitue le backend d'une application web de gestion de produits, développé avec Node.js, Express et MongoDB.  
Il gère l’authentification des utilisateurs via JWT ainsi que les opérations CRUD sur les produits et les catégories.  


---


##  Technologies

- Node.js
- Express.js
- MongoDB + Mongoose
- JWT pour l’authentification
- bcryptjs pour le hachage des mots de passe
- dotenv, cors

---

##  Fonctionnalités

-  Authentification (Inscription / Connexion)
-  CRUD Produits
-  CRUD Catégories
-  Routes protégées avec token JWT
